# JZDS: A simple data structures C library

Note: for now, this library is designed with my personal use in mind.
Having implemented a dynamic array for the 20th time, I simply became
quite frustrated.

Following data structures are under development:
 - dynamic array (dynarr)
 - array-based double-ended queue (arrdeq)
 - two-dimensional static array (arr2d)
